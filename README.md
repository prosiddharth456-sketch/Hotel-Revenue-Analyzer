\# 🏨 Hotel Revenue Analyzer



\## 📌 Project Overview



The \*\*Hotel Revenue Analyzer\*\* is a Python-based data analysis project that calculates and visualizes hotel revenue using data stored in a CSV file.



It helps analyze daily hotel revenue, identify the best-performing day, and compare revenue generated by different room types.



\## 🎯 Objectives



\- Calculate revenue from hotel room sales.

\- Analyze daily revenue and total revenue.

\- Identify the day with the highest revenue.

\- Calculate revenue and revenue percentages by room type.

\- Visualize revenue data using charts.

\- Handle invalid records and missing CSV files gracefully.



\## 🛠️ Technologies Used



\- \*\*Python 3\*\* — Core programming language

\- \*\*Pandas\*\* — Data processing and analysis

\- \*\*Matplotlib\*\* — Data visualization

\- \*\*CSV\*\* — Input data format



\## ✨ Features



1\. \*\*Daily Revenue Analysis:\*\* Calculates revenue for each date.

2\. \*\*Total Revenue:\*\* Displays the total revenue generated.

3\. \*\*Best-Performing Day:\*\* Identifies the date with the highest revenue.

4\. \*\*Room-Type Analysis:\*\* Calculates revenue and percentage contributions for each room type.

5\. \*\*Data Visualization:\*\* Displays charts for revenue analysis.

6\. \*\*Error Handling:\*\* Skips invalid records and handles missing files.

\## 📊 Input Data Format



The input CSV file must contain these columns:



| Column | Description |

|---|---|

| `Date` | Date of the room sale |

| `RoomType` | Type of hotel room |

| `RoomsSold` | Number of rooms sold |

| `Rate` | Price per room |



Revenue is calculated using:



\*\*Revenue = RoomsSold × Rate\*\*
